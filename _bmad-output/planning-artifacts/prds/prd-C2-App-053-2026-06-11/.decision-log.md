- **2026-06-11**: Updated Section 6.1 (MVP In-Scope) to explicitly include DOCX file manual uploading and parsing alongside PDFs.
- **2026-06-11**: Added Section 4.6 (System Configuration) with FR-11 and FR-12 to support Admin limit adjustments, setting the initial default paper limit per project to 15 to ensure LLM processing efficiency and prevent context clutter.
- **2026-06-11**: Clarified search mechanism in FR-3: Keyword Search (utilizing API providers' relevance ranking) matching Title, Abstract, Authors, and Venue fields. Added support for AI keyword extraction from chat messages and deduplication based on DOI/Title.

- **2026-06-11**: Confirmed search matching is delegated to the online API providers (arXiv & Semantic Scholar). Approved on-demand queries with persistent local metadata caching (in PostgreSQL) only for user-added papers, rejecting the option to download and mirror the entire academic dataset locally due to storage size and data staleness.
- **2026-06-11**: Updated FR-4 and FR-5 to allow users to add paid papers (metadata/abstract only) to projects. The papers will be visible in the project list and Knowledge Map, and users can manually upload full-text PDFs/DOCXs later to overwrite the "Awaiting manual upload" state and perform deep RAG analysis.
- **2026-06-12**: PRD provisionally approved by user Dat. Status updated to 'final'. Closed PRD planning phase to proceed to technical Architecture design.
- **2026-06-12 (Redesign Update)**: Updated PRD with system design philosophy, emphasizing Project-centricity (onboarding barrier, recent projects sidebar, "View All" page) and the Chatbot as the central project-wide active companion. Specified redundant control pathways (GUI and conversational commands synchronized in real-time) and clarified that the chatbot only reminds/warns about the file limits (FR-11) while the actual configuration remains restricted to the Admin role.
