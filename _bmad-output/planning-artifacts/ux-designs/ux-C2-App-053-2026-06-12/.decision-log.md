# Decision Log - C2-App-053 UX Design

This log tracks key design decisions made during the UX design process.

## Log

- **2026-06-12**: Initialized workspace for UX Design.
- **2026-06-12 (Pivoted)**: Rejected Google Stitch dark obsidian/cyan design system. Decided to switch to Coaching Path and restart discovery from scratch.
- **2026-06-12 (Redesign - Discovery Phase)**:
  - **Working Mode**: Coaching Path (Collaborative design specification drafting).
  - **Theme Posture**: Light Mode by default. Soft warm white/slate palette to reduce eye strain. Dark Mode is optional (toggled via header) and uses soft dark gray-slate (moderate darkness, not deep pitch black).
  - **Layout Structure**: 
    * Left panel: Project/Workspace navigation sidebar (fixed, width 240px). Focuses purely on workspace navigation (Logo, "+ Phân tích mới", Projects dropdown, "Bản đồ Tri thức", "Thư viện Tài liệu", "Lịch sử Phân tích").
    * Top-right header: Consolidated utilities bar containing: "Trợ giúp" (Help), "Cài đặt Hệ thống" (Settings gear), "Đăng xuất" (Sign Out), Language Selector (VI/EN), and Light/Dark Mode toggle. This removes bottom sidebar clutter.
    * Center panel: Primary workspace (shows Cytoscape.js Knowledge Map or Document Library list).
    * Right panel: AI Chatbot assistant panel, taking up 20% to 25% (1/4 to 1/5) of screen width.
  - **Layout Interactivity**: 
    * The right Chatbot panel is resizable (users can drag the left border to adjust its width) and collapsible (can be toggled open/closed via a header button).
  - **Visual Anchors & Palette (Light default)**:
    * Primary background: `#FAF9F6` (Warm paper)
    * Cards & panels background: `#FFFFFF` (Pure white)
    * Text color: `#1E2022` (Deep charcoal)
    * Primary Accent: `#2563EB` (Cobalt blue for buttons, citations, and `:CITES` relation edges)
    * Secondary Accent: `#8B5CF6` (Amethyst violet for `:AUTHORED` relation edges)
    * Border lines: `#E2E8F0` (Soft gray)
- **2026-06-12 (Final Refinement & Approval)**: Refined the layout by moving "Cài đặt Hệ thống" (System Settings), "Trợ giúp" (Help), and "Đăng xuất" (Sign Out) from the sidebar and bottom panel to the Top-Right Header Utilities Bar, creating an exceptionally clean left sidebar focused purely on workspace views. Generated new visual mockup `academic_paper_dashboard.png` showing this header. Set design specifications status to `final`.
- **2026-06-12 (Sidebar Visual Hierarchy)**: Restructured the Left Sidebar into two distinct, vertically separated visual zones: (1) Top Section (Quản lý Dự án) for project selection and creation, and (2) Bottom Section (Tính năng Dự án) for project-specific tabs (Bản đồ Tri thức, Thư viện Tài liệu, Lịch sử Phân tích), clearly demonstrating that features are nested inside and dependent on the active project. Updated both mockup images to reflect this hierarchy.
- **2026-06-12 (Tabs Moved to Center Panel)**: Pivoted the layout structure to move all project-specific tabs ("Bản đồ Tri thức", "Thư viện Tài liệu", "Lịch sử Phân tích") from the left sidebar to the top header of the Center Panel (level with the Chatbot Panel header). Left Sidebar is now exclusively dedicated to Project Management (Project Workspace CRUD, Project List switcher). This strongly reinforces project-centric encapsulation. Updated mockup images to reflect this refined tabs layout.
- **2026-06-13 (Homepage Design Addition)**: Added interaction and styling specifications for Guest Homepage (landing page with a high-fidelity Interactive Demo Simulator of arXiv/Semantic Scholar academic search and Cytoscape.js gap detection) and User Homepage (responsive Project Selector Grid Dashboard). Designed the integrated onboarding screen for users with 0 projects to display both a creation form and quick tutorials side-by-side.
- **2026-06-13 (Validation Updates & Component Alignment)**: Thực hiện kiểm định thiết kế UX. Phát hiện và khắc phục các điểm không nhất quán: chuẩn hóa 100% tên gọi và số lượng component giữa hai tài liệu, đặc tả các trạng thái giao diện cơ bản (empty, loading, error) trên toàn bộ bề mặt IA, bổ sung Key Flow 4 cho luồng Đăng ký & Đăng nhập (FR-1), và điều chỉnh thông báo giới hạn tài liệu bám sát cấu hình Admin trong PRD thay vì đề cập gói cước thanh toán.
- **2026-06-13 (Chat Input Position Refinement)**: Điều chỉnh vị trí ô nhập liệu của Chatbot Panel từ cố định ở dưới cùng lên trên các đoạn hội thoại (nằm dưới cụm nút ngang hàng "Lịch sử trò chuyện" và "Trò chuyện mới") theo yêu cầu phản hồi từ phía người dùng. Đồng thời tạo mới các tệp mockup visual để trực quan hóa chính xác thiết kế cập nhật này.
